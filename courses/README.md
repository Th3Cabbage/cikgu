# Courses

Each subject has one folder. Teaching content, browser assets, render sources and package-specific
documentation live with the course. Shared launchers, authoring tools, tests and website
infrastructure remain at the repository root.

- [controls/](controls/README.md): Control Bootcamp lecture series.
- [ode/](ode/README.md): Second-Order Linear Differential Equations, browser and native versions.

Future subjects use `courses/<subject>/`; multi-lecture subjects use one subfolder per lecture.
Register finished packages in `site/catalog.json` so they appear in the unified website.
